# Analysis Scripts

This directory contains scripts for analyzing fantasy football data and generating insights.

## Files:

### Team & Field Analysis
- **`compare_team_fields.py`** - Compare team field discrepancies and data quality
- **`augment_weekly_team_opponent.py`** - Add team and opponent information to weekly stats

### Defense Analysis
- **`compute_defense_adjusted_metrics.py`** - Calculate defense-adjusted performance metrics
- **`defense_schedule.py`** - Analyze defensive schedules and matchups

### Data Inspection
- **`inspect_box_scores.py`** - Inspect and validate box score data
- **`top-scorers.py`** - Identify top performing players

### Player Analysis
- **`check_player_stats_2019.py`** - Analyze 2019 player statistics
- **`yahoo_quickstart.py`** - Yahoo fantasy football API integration

## Usage:
These scripts are for exploratory data analysis and can be run independently to investigate specific aspects of the fantasy football data.
