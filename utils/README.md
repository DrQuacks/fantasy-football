# Utility Scripts

This directory contains utility scripts for debugging, testing, and general development tasks.

## Files:

### Debugging Scripts
- **`debug_arizona_calculation.py`** - Debug Arizona team calculations
- **`debug_arizona_calculation_corrected.py`** - Corrected version of Arizona calculations
- **`debug_features.py`** - Debug feature engineering and data processing

### Testing Scripts
- **`test_david_moore.py`** - Test script for David Moore player data
- **`sanity.py`** - Sanity checks for data integrity

### Data Exploration
- **`peek_team_and_opponent.py`** - Quick look at team and opponent data
- **`peek_json.py`** - JSON data inspection utility
- **`probe_raw.py`** - Raw data probing and inspection
- **`probe_espn_view.py`** - ESPN view data probing
- **`extract_week_content.py`** - Extract weekly content from data

### Development Tools
- **`gui_json_explorer.py`** - GUI tool for exploring JSON data
- **`playground.py`** - Development playground for testing ideas

## Usage:
These are development and debugging tools. Most can be run independently for specific debugging or exploration tasks.
